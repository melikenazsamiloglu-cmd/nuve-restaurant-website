# NÜVE | Tohumdan Tabağa

**NÜVE**, gastronomi, yerel üretim ve sürdürülebilirlik temalarını buluşturan bir restoran konsepti için hazırlanmış çok sayfalı bir web arayüzü projesidir. Web sitesinin tüm arayüz tasarımı ve kaynak kodları **Melike Naz Şamiloğlu** tarafından hazırlanmıştır. Gastronomi öğrencisi **Yaren Ertürk**, projenin gastronomi perspektifine katkı sağlamıştır.

> **Proje durumu:** Konsept / web tasarımı prototipi. Gerçek bir restoranın faaliyette olduğunu veya bu site üzerinden rezervasyon alınabildiğini göstermez.

## Proje hakkında

Site, Seferihisar esinli bir gastronomi deneyimini ve "tohumdan tabağa" yaklaşımını ziyaretçiye görsel olarak anlatmayı amaçlar. Tasarımda koyu arka plan, altın tonlu vurgular, tipografi ve fotoğraf/video içerikleri kullanılmıştır.

## Teknolojiler

- **HTML5:** çok sayfalı site yapısı ve içerik
- **CSS3:** sayfa yerleşimi, görsel tasarım ve duyarlı menü
- **Haricî servis:** Google Fonts (Cinzel ve Montserrat)

Mevcut kaynak dosyalarda JavaScript uygulaması veya sunucu tarafı kod bulunmamaktadır. Proje statik bir web sitesi olarak hazırlanmıştır.

## Sayfalar

| Dosya | Açıklama |
| --- | --- |
| `index.html` | Ana sayfa ve konsept tanıtımı |
| `hakkimizda.html` | Marka/konsept hikâyesi |
| `menu.html` | Menü kategorileri |
| `alakart.html` | Alakart menü |
| `tadim.html` | Tadım deneyimi |
| `icecek.html` | İçecek menüsü |
| `misafirhane.html` | Misafirhane konsepti |
| `tohum-evlat-edinme.html` | Tohum kütüphanesi konsepti |
| `rezervasyon.html` | Rezervasyon ekranı tasarımı (demo) |

## Çalıştırma

1. Bu depoyu indir veya klonla.
2. `index.html` dosyasını bir web tarayıcısında aç.
3. Ana sayfadaki bağlantılarla diğer sayfalara geç.

Ek bir paket kurulumu veya derleme aşaması gerekmemektedir. Çevrim içi yazı tiplerinin görüntülenmesi için internet bağlantısı gerekebilir.

## Mevcut sınırlar

- `rezervasyon.html` sayfasındaki form **görsel prototiptir**: `action="#"` kullanır, veri kaydetmez ve gerçek rezervasyon oluşturmaz.
- Dinamik yönetim paneli, ödeme veya kullanıcı hesabı sistemi bulunmaz.
- Bu depo, geliştirilen web arayüzünün örnek çalışmasını ve kaynak dosyalarını sergiler.
